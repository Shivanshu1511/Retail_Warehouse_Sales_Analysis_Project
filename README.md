🧾 Retail & Warehouse Sales Analysis Project
📊 Project Overview

This project demonstrates a complete Excel-based data analysis workflow using real-world retail and warehouse sales data.
The goal is to analyze sales performance across suppliers, item types, and time periods — and create an interactive Excel dashboard that highlights key business insights.

🎯 Objectives

Clean and transform raw sales data for analysis

Identify top suppliers, item types, and sales trends

Visualize sales KPIs with an interactive Excel dashboard

🧩 Dataset Details

File Name: Warehouse_and_Retail_Sales.csv
Rows: 3,07,645
Columns: 9

Column Name	Description
YEAR	Year of sale
MONTH	Month of sale
SUPPLIER	Supplier name
ITEM CODE	Unique product code
ITEM DESCRIPTION	Product details
ITEM TYPE	Product category (e.g., WINE, BEER, etc.)
RETAIL SALES	Retail units sold
RETAIL TRANSFERS	Inventory moved to retail
WAREHOUSE SALES	Units sold via warehouse
🧹 Data Cleaning & Preparation

Steps performed in Excel:

Imported data using Power Query / Get Data → From Text/CSV

Removed duplicates and filled missing values

Created new columns:

Total Sales = Retail + Warehouse

Complete sales = Retail + Reatil transfer + Warehouse

Standardized supplier names (TRIM, PROPER)

📈 Analysis Performed

Monthly sales trend analysis

Supplier-wise sales ranking

Item type performance comparison

Top 10 suppliers and top 10 items

Excel Features Used:
VLOOKUP,  DATE, Pivot Tables, Pivot Charts, Slicers, Timelines, Conditional Formatting

📊 Dashboard Highlights

The Excel Dashboard includes:

Line Chart → Monthly Sales Trend

Column Chart → Top 10 Suppliers

Pie Chart → Item Type Sales Share

Slicers for Year, Supplier, and Item Type
